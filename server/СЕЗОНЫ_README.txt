СЕЗОНЫ (plugins/Skript/scripts/paxseasons.sk, 2026-11-16, на живом сервере ещё не запускалось)
=========================================================================================
Нужны: Skript + skript-reflect + Towny. Включаются сами с 29-го дня после /paxborder start
(недели 1–3 — paxweeks.sk, неделя 4 — Великая война paxwar.sk). Каждая реальная неделя — новый сезон:

  Весна «Посевная»        урожай растёт быстрее (random tick speed 4); сбросы с семенами и едой
  Лето «Экспедиции»       сбросы припасов каждые 90 минут вместо 120, богаче (алмазы, изумруды, порох)
  Осень «Сбор урожая»     /season harvest — 64 шт. пшеницы/моркови/картофеля/свёклы/тыквы в руке
                          → 40$ в казну вашего города
  Зима «Зимняя кампания»  на территории чужих (не своих и не союзных) городов — Замедление I;
                          урожай растёт медленнее (random tick speed 2). Атакующим зимой тяжелее — как в HOI4.

Сброс припасов (все сезоны): при 3+ игроках онлайн раз в 2 часа (летом раз в 90 мин) в дикой местности
внутри бордера появляется сундук, координаты объявляются в чате и Discord ([Событие]).
Через 30 минут несобранный сундук исчезает.
С 2026-11-18 сундук не падает в личные приваты (paxclaims.sk) — раньше его мог открыть только владелец привата.

Команды:  /season (/сезон) — текущий сезон и активный сброс
Админ (OP / paxseasons.admin):  /season admin set весна|лето|осень|зима|авто  ;  /season admin drop
Смена сезона объявляется с префиксом [Сезон] и уходит в Discord.
