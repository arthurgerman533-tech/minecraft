ПОМОЩНИКИ (AxMinions 1.0.21, Modrinth, MIT, SHA512 проверен)
================================================================
Файлы:
  plugins/AxMinions-1.0.21-all.jar
  plugins/AxMinions/config.yml   — лимит 1 помощник на игрока, сундук не дальше 8 блоков,
                                   инструмент не ломается до конца (помощник просто встаёт)
  plugins/Skript/scripts/paxhelpers.sk — ивент 2-й недели

Как работает:
  * С 7-го дня после /paxborder start в чате объявление, игрок пишет /помощник шахтёр
    или /помощник сборщик и получает помощника + «Сундук помощника». Один раз на игрока.
  * Шахтёр копает ТОЛЬКО булыжник/камень с генератора (вода + лава рядом) — руды не фармит.
  * Сборщик подбирает упавшие предметы вокруг себя (рядом с фермой/мобоферми).
  * Всё складывается в привязанный сундук: ПКМ по помощнику -> Link to container -> клик по сундуку.

Баланс / совместимость:
  * Остальные типы (лесоруб, фермер, рыбак, убийца мобов, продавец, крафтер) игрокам не выдаются.
  * Улучшения уровней платные (VaultUnlocked + EssentialsX): от 500$ за ур.2 до 1 000 000$ за ур.10,
    цены в plugins/AxMinions/minions/*.yml, подробнее в ЭКОНОМИКА_README.txt.
  * Towny: AxMinions имеет встроенную поддержку Towny — поставить помощника можно только там,
    где игрок может строить. Ломать/открывать — только владелец.
  * GrimAC: помощники — пакетные сущности, игроков не двигают, конфликтов нет.

Админ:
  /paxhelpers open | close | status | reset <ник>
  /axminions extraslot <ник> <кол-во>  — дать доп. слот (например, мэру/награда за войну)
  /axminions give <ник> miner|collector 1 1
