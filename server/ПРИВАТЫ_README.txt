ЛИЧНЫЕ ПРИВАТЫ ЧЕРЕЗ БЛОКИ — PaxVanila (скрипт plugins\Skript\scripts\paxclaims.sk)
=================================================================================

Нужно: Skript 2.17.1 + skript-reflect 2.6.3 (положен в plugins, сверен с GitHub-релизом по SHA256) + Towny.
skript-reflect нужен и paxwar.sk / paxweeks.sk — без него они тоже не грузились.

ДЛЯ ИГРОКОВ (можно в Discord):
  Присядьте (Shift) и поставьте блок — вокруг появится приват на всю высоту:
    медный блок   — 11x11
    железный блок — 21x21
    золотой блок  — 31x31
    алмазный блок — 51x51
  Без Shift блок ставится как обычный декор.
  Лимит: 3 привата на игрока. Сломали свой блок привата — приват снят.
  /claim (или /приват) — инфо о месте, где стоите
  /claim list — мои приваты       /claim show — подсветить границу на 15 сек
  /claim add <ник> / remove <ник> — пустить/убрать друга
  /claim tiers — тиры

ПРАВИЛА:
  - В чужом городе Towny приватить нельзя, в своём можно (личный участок).
  - Не ближе 80 блоков к спавну (башня 0,0), без пересечений с чужими приватами.
  - Защищено: ломать/ставить, сундуки/двери/кнопки (любой ПКМ по блоку), вёдра,
    животные/жители/стойки, взрывы, огонь, поршни и жидкости снаружи, нажимные плиты.
  - ВОЙНА: пока между двумя нациями идёт бой (/paxwar: прайм-тайм 17–22 МСК, >= 2 защитника),
    враги могут ломать, открывать сундуки и взрывать приваты друг друга.
    Блок привата неуязвим всегда (анти-руины). Новички (48 ч) не рейдят и их не рейдят.

АДМИН (право pax.claims.admin, у операторов есть):
  строит везде, /claim del — удалить приват, в котором стоишь, лимит на него не действует.
  Настройки (лимит, радиус спавна, часы новичка) — в options в начале скрипта, радиусы в pcRadius.

ПРОВЕРИТЬ ПРИ ЗАПУСКЕ (скрипт ещё не запускался на сервере):
  /sk reload paxclaims — в консоли не должно быть ошибок. Если ругается на "copper block" и т.п.,
  напишите — поправлю название блока.
  Закрыто 2026-11-18: поршни снаружи (толкать и тянуть блоки привата), вода/лава, затекающая
  в приват снаружи, нажимные плиты/растяжки/вытаптывание грядок чужими. Внутри своего привата
  поршни и фермы работают как обычно. Эти 4 обработчика — события skript-reflect
  ("org.bukkit.event...") в конце раздела «защита» paxclaims.sk.
