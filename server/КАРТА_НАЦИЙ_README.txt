ТЕРРИТОРИИ НАЦИЙ НА BLUEMAP — 2026-11-16
=========================================
Плагин: plugins/BlueMap-Towny-2.4.0.jar (Modrinth, GPL-3.0, заявлены 26.1–26.2, SHA512 сверен).
Нужны BlueMap (есть: bluemap-5.29) и Towny.
Настройки: plugins/BlueMap-Towny/config.yml (переведено на русский).

Что видно на карте:
  * Слой «Государства»: границы и заливка каждого города, аванпосты.
  * Цвет — цвет нации (глава: /n set mapcolor <цвет>) или города (/t set mapcolor <цвет>).
    Города без нации и без цвета — серые.
  * Всплывающее окно: город (нация), мэр, жители, казна.
  * Обновление раз в 30 секунд.

Важно про Minehut: веб-карта BlueMap работает через свой веб-сервер (порт 8100 по умолчанию).
Если хостинг не открывает дополнительный порт, карту в браузере не открыть. Тогда варианты:
  — хостинг с доп. портом / прокси, или
  — BlueMap "внешний веб-сервер" (выгрузка карты на отдельный сайт), см. документацию BlueMap.
