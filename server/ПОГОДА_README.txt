ПаксГидромет и «Вестник Академии» — погода, катаклизмы и научные новости
=========================================================================

Что это
-------
На сайте и в приложении есть раздел «Погода · ПаксГидромет» (сводка, предупреждения
по уровням опасности, справочник катаклизмов, прогноз сезонов, журнал) и лента
«Вестник Академии» (что узнали учёные: первые находки данжей + статьи по лору).

Пока сервер не публикует данные, оба раздела показывают демо с красной пометкой «ДЕМО».

Файлы
-----
  content/meteo.json        справочник: катаклизмы, шансы, длительность, советы, сезоны
  content/meteo_demo.json   демо-сводка для сайта
  content/news.json         категории, шаблоны заметок о находках, статьи по лору
  content/news_demo.json    демо-находки
  server/plugins/Skript/scripts/paxmeteo.sk   пишет живые meteo.json и news.json

Что делает paxmeteo.sk
----------------------
  * раз в минуту пишет сводку погоды в plugins/PaxMeteo/meteo.json
    (катаклизм из датапака, предупреждение, сезон, день, погода, онлайн);
  * запоминает последние 20 катаклизмов (журнал);
  * когда игрок ПЕРВЫМ на сервере получает достижение (черепок, залы испытаний,
    Древний город, крепость Незера, бастион, крепость с рамкой, Край, дракон,
    город Края, Иссушитель), пишет в чат «[Вестник Академии] …» и добавляет заметку
    в plugins/PaxMeteo/news.json.

Нужны Skript 2.17+, skript-reflect и скрипты paxweather_discord.sk, paxseasons.sk,
paxborder.sk (из них берутся данные). Датапак катаклизмов не меняется.

Команды
-------
  /meteo  (/погода, /гидромет)   сводка в чате
  /meteo write                    записать файлы сейчас        (право paxmeteo.admin)
  /meteo admin reset              забыть находки и журнал      (право paxmeteo.admin)

Как включить живые данные на сайте
----------------------------------
1. Файлы должны быть доступны из интернета. Проще всего через веб-сервер BlueMap:
   в paxmeteo.sk поменяйте в options
       out: plugins/PaxMeteo
   на папку веб-карты, например
       out: plugins/BlueMap/web/live
   и выполните /sk reload paxmeteo, затем /meteo write.
   Проверьте в браузере: http://<адрес сервера>:8100/live/meteo.json
2. В content/paxvanila.json впишите
       "liveUrl": "http://<адрес сервера>:8100/live/"
   и пересоберите сайт: python3 tools/build_site.py, затем закоммитьте docs/.

Важно:
  * Сайт открыт по https (GitHub Pages), а браузер не даёт https-странице читать http.
    Поэтому для сайта нужен https-адрес (например, домен с сертификатом через nginx
    или Cloudflare). Приложение читает и http.
  * Веб-сервер должен отдавать заголовок Access-Control-Allow-Origin: *
    (в nginx: add_header Access-Control-Allow-Origin *;). Иначе сайт молча
    покажет демо-данные.

Что попадает в файлы: номера катаклизмов, время, число игроков онлайн и ник первооткрывателя.
