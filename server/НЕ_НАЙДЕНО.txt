НЕ НАЙДЕНО:

1. ChoiceTheorem's Overhauled Village (CTOV) — ДАТАПАК-версия
   - На Modrinth (https://modrinth.com/mod/ct-overhaul-village) для 26.2 есть только моды:
     [Fabric]CTOV-26-2-4.1.1.jar и NeoForge 4.1.1. Загрузчика "datapack" у проекта нет вообще.
   - GitHub (ChoiceTheorem/ChoiceTheorem-s-overhauled-village) — последний релиз v.3.3.1 от 2023 года.
   - Датапак-версия, видимо, есть только на CurseForge (не входит в список разрешённых источников).
   - Fabric-jar НЕ подкладывал: он содержит mixin'ы (код мода), как датапак на Paper он не гарантирован.

2. Lithostitched — датапак-версии не существует
   - Это только мод (Fabric / Forge / NeoForge), последняя для 26.2: 1.8.0 (fabric/neoforge, 2026-09-22).
   - На Paper не работает и нужен только моду CTOV. Без CTOV-датапака он не нужен.

ПОД ВОПРОСОМ (положено, но проверьте):

3. WeaponMechanics 4.3.1 + MechanicsCore 4.3.1 (GitHub, последний релиз от 2026-05-29)
   - Явной поддержки 26.2 нигде не указано: на SpigotMC отмечено "tested 1.21, 26.1".
     Релиз вышел до выхода 26.2, т.е. это поддержка 26.x, а не именно 26.2.
   - Ресурс-пак WeaponMechanicsResourcePack-3.0.0.zip (из того же релиза) НЕ положен в plugins —
     его нужно настроить как resource pack сервера отдельно (скачать из релиза v4.3.1 на GitHub).

4. Structory 1.3.17 и Structory: Towers 1.0.17 — в pack.mcmeta max_format = [107, 1].
   Terralith для 26.2 объявляет формат 107, Modrinth у обоих указывает 26.2 — должно работать,
   но если 26.2 использует формат выше 107.1, сервер их отключит (смотрите лог при старте).

5. Towns and Towers — отдельной сборки "26.2" нет, взята 26.1-datapack (файл t_and_t-datapack-26.x.zip),
   в ней Modrinth указывает 26.1–26.2, pack.mcmeta: форматы 88–1000.

6. PlasmoVoice — взят последний РЕЛИЗ 2.1.17. Есть более новые бета-версии 2.2.0-beta.1..3 — не брал.

7. MTVehicles 2.5.9 (Modrinth, 2026-10-28) — заявлены 26.1.2, 26.2, 26.3 → включён в сборку.
