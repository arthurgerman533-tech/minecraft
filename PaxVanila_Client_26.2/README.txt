PaxVanila Client 26.2 (Fabric 0.20.1, Minecraft 26.2) — клиентская сборка

Установка (вариант 1, проще):
  Modrinth App или Prism Launcher -> Импорт -> PaxVanila_Client_26.2.mrpack
  Лаунчер сам скачает все файлы с Modrinth и проверит хэши.

Установка (вариант 2, вручную):
  1. Поставь Fabric Loader 0.20.1 для 26.2 (fabricmc.net/use/installer).
  2. Скопируй папки mods, shaderpacks, resourcepacks в папку игры (.minecraft или папку профиля).

После первого запуска:
  - Шейдеры: Настройки -> Видео -> Shader Packs.
      Complementary Reimagined  — красивый основной.
      Yukee Shaders             — аниме-стиль (рисованные облака, пастельные цвета, контуры).
      Animetro                  — лёгкий cel-shading для слабого ПК.
  - Ресурспак: включи Fresh Animations (анимации мобов, работает через EMF+ETF).
  - Xaero's Minimap: открой настройки (Y) -> Entity Radar и выключи отображение игроков.
    По правилам сервера мини-карта разрешена только без радара игроков.
  - Зум: клавиша C (Zoomify).

Не добавлять: X-ray, fly, радары игроков, шейдеры с подсветкой руды сквозь блоки.
